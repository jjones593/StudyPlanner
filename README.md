# StudyPlanner

## Team Members
Jake Jones, Thomas Squires, Anna Horlick

## Problem Statement 
We propose to create a study planner for students taking several courses to help them keep track of when
their assignments, labs, and projects are due. This will increase the student's productivity and help them
better manage their time and stay organized throughout the semester.

## Stakeholder Analysis
This application will be useful for students who want a way to track their due dates. It can be especially
useful to students who have trouble with time management skills, as they can use the calendar to aid in
planning their week. 

## Key Features
This application will have:

- A place where students are able to add their current courses.
- A calendar which will show the times throughout the week a student has a particular class/lab,
this will also be able to show deadlines for assignments, test dates, etc.
- A reminder feature that can notify when an evaluation is coming up.
- An area where you can enter grades for individual courses.
- An area for making notes.
