# User Stories

## US-01: Add a Course
As a user, I want to add a course to organize schoolwork by course.
### Related Requirements
FR-01: Course Management
### Acceptance Criteria
- The user can enter a course name.
- The user can enter a course code.
- The user can save the course.
- The saved course appears in the course list.
- The user can cancel the course selection.
### Story Points
3

## US-02: Edit/ Delete a Course
As a student, I want to be able to edit/ delete a course.
### Related Requirements
FR-01 Course Management
### Acceptance Criteria
- The user can edit course name/ number.
- The user can delete course.
- The user can save changes.
- The system asks for confirmation before deleting a course.
### Story Points
3

## US-03: Add Calendar Event
As a student, I want to add assignments and events to my calendar.
### Related Requirement
FR-02: Assignments and Events
### Acceptance Criteria
- The user can create a new calendar event.
- The user can enter an event title.
- The user can select a date.
- The user can enter a time.
- The user can associate the event with a course.
- The event appears on the calendar after being saved.
### Story Points
5

## US-04: View Calendar
As a student, I want to view my assignments and events on a calendar.
### Related Requirement
FR-03: Calendar
### Acceptance Criteria
- The user can open the calendar.
- The calendar displays the user's saved events.
- Events display their title and date.
- The user can navigate between different dates.
- The user can distinguish between different events on the calendar.
### Story Points
5

## US-05: Edit/ Delete Calendar Event
As a student, I want to edit or delete calendar events.
### Related Requirement
FR-02: Assignments and Events
### Acceptance Criteria
- The user can select an existing calendar event.
- The user can edit the event information.
- The user can save changes to the event.
- The user can delete an event.
- The system asks for confirmation before deleting an event.
- Changes are reflected on the calendar.
### Story Points
3

## US-06: Set Reminders
As a student, I want to set reminders for assignments and events.
### Related Requirement
FR-04: Reminders
### Acceptance Criteria
- The user can create a reminder for an assignment or event.
- The user can select when they want to be reminded.
- The reminder is associated with the correct assignment or event.
- The user can edit a reminder.
- The user can delete a reminder.
### Story Points
5
