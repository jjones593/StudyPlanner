# Agile Software Requirements Specification

## Functional Requirements

### FR-01 Course Management
The system shall allow users to be able to add, edit, and delete courses.
### FR-02 Assignments and Events
The system shall allow users to add tests, assignments, and events. 
### FR-03 Calendar
The system shall display tests, assignments, and events in a calendar.
### FR-04 Reminders
The system shall allow users to set reminders for upcoming deadlines.
### FR-05 Notifications
The system shall provide notifications for upcoming deadlines.
### FR-06 Grades Entry
The system shall allow users to manually enter grades.
### FR-07 View Grades
The system shall allow users to view their grades.
### FR-08 Notes
The system shall allow users to create, edit, and delete notes.
### FR-09 Course Associatation
The system shall allow assignments to be associated with specific courses.
### FR-10 Edit/ Delete Information
The system shall allow the user to edit or delete entered information.

## Non-Functional Requirements

### NFR-01 Response Time
The application should respond quickly to user actions.
### NFR-02 Storing Information Reliably
User information should be stored reliably.
### NFR-03 Invalid Information
The application should prevent invalid information from being entered.
### NFR-04 Supported Devices
The application should work consistently accross supported devices/platforms.

## Constraints

### C-01 Data Constraint
Users must manually enter their own courses, test, assignments, and notes. The system will not retrieve grades automatically. 
### C-02 Scope Constraint
The project will focus on core study planning, it will not be a complete learning system.
### C-03 Team Constraint
The project must be completed by the assigned team members.
### C-04 Security Constraint
The application must protect user information and not store sensitive information unnecessarily.
