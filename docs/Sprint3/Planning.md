# Sprint 3 Planning
## Sprint Goal 
- Implement reminder and notification features to help students keep track of upcoming deadlines, while adding the ability to enter and view grades for their courses.

## Selected Product Backlog Tasks
- US-06 Set Reminders
- US-07 Receive Notifcations
- US-08 Enter Grades
- US-09 View Grades

## Tasks and Subtasks
### US-06 Set Reminders
- The user can create a reminder for an assignment or event.
- The user can select when they want to be reminded.
- The reminder is associated with the correct assignment or event.
- The user can edit a reminder.
- The user can delete a reminder.

### US-07 Recieve Notifications
- The system checks for upcoming reminders.
- The user receives a notification when a reminder is due.
- The notification identifies the related assignment or event.
- The notification includes the relevant deadline.
- Notifications are only sent for active reminders.

### US-08 Enter Grades
- The user can select a course.
- The user can enter a grade.
- The user can enter the assessment name.
- The user can save the grade.
- The grade is associated with the correct course.
- The system prevents invalid grade values from being entered.

### US-09 View Grades
- The user can view grades for each course.
- Grades are displayed with the associated assessment.
- The user can identify which course each grade belongs to.
- The system displays saved grades accurately.
- The user can view their grades after restarting the application.
  
## Definition of Done
- Code committed
- Pull request approved
- Unit tests executed
